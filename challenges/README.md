# Challenges

Create one file per challenge from `_template.md` (e.g. `dancing-with-the-sars.md`). Full statements and datasets are published on **28 Oct 2026** at https://www.spaceappschallenge.org/2026/challenges/.

## Known so far (from press coverage, 12 Oct 2026; 14 challenges in total)

| Challenge | Level | Summary |

| Interplanetary Survival Guide: Martian Map | Beginner | Interactive map for exploring and navigating Mars |
| Space Mission Design Game | Beginner | Game where players design and run their own mission |
| The Earth Information Jukebox | Beginner | Turn NASA Earth data and imagery into sound |
